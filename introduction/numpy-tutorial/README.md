## NumPy Quick Tour (Runnable Examples)

This script provides a compact, runnable tour of NumPy essentials. Each section prints small outputs so you can see the effect of each API call without plotting.

## What it covers
- Arrays, shapes, dtypes, indexing, slicing
- Copies vs views, reshape, flatten
- Iteration (`nditer`, `ndenumerate`)
- Concatenation and stacking (`concatenate`, `hstack`, `vstack`, `dstack`)
- Splitting (`array_split`, `hsplit`)
- Search and sort (`where`, `searchsorted`, `sort`)
- Boolean filtering
- Random sampling (`randint`, `rand`, `choice`, probabilities), shuffling vs permutation
- Ufuncs and vectorized arithmetic (add, subtract, multiply, divide, power, mod)
- Rounding (`trunc`, `fix`, `around`, `floor`, `ceil`)
- Logs (`log`, `log2`, `log10`)
- Reductions (`sum`, `prod`, `cumsum`, `cumprod`) and `diff`
- Number theory (`lcm`, `gcd`)
- Trig and hyperbolic functions
- Set operations (`unique`, `union1d`, `intersect1d`, `setdiff1d`, `setxor1d`)
- Compact samples of common random distributions (normal, binomial, poisson, uniform, logistic, multinomial, exponential, chi-square, rayleigh, pareto, zipf)
